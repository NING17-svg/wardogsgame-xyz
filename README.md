# WARDOGS Guide

This repository hosts the V3 game-guide site for **WARDOGS** (BULKHEAD-developed,
Team17-published 100-player three-squad tactical FPS, Steam AppID 1867240). The site
is built from the shared `game-guide-site-template` and is operated by the
`one-click-builder` automation.

The neutral theme and empty asset manifest are development fallbacks only. The
approved WARDOGS theme (night-ops tactical command surface) is implemented by
`site-theme-implementer` after bootstrap completes.
